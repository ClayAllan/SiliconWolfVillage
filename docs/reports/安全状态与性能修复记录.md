## 安全配置说明

- 默认允许的主机是 `api.deepseek.com` 与 `api.openai.com`，仅允许 HTTPS。
- 自定义公网服务必须由部署者显式添加到 `SWV_ALLOWED_MODEL_HOSTS`。这是精确主机名列表，不支持通配符。
- `SWV_ALLOW_PRIVATE_MODEL_URLS=1` 只供可信本地/自托管开发使用；不应在公共托管实例启用。
- 自定义域名允许列表是应用层边界。若部署环境支持，应进一步以网络出口策略限制服务端可访问的目的地址。
- 归档仍需按数据保留策略管理；脱敏只针对 Base URL 元数据，不意味着原始 API 证据不含敏感对话内容。
