# AI 竞技场：离线批量评测

此工具只分析已有归档，不启动新对局、不发起模型 API 请求，也不估算不可靠的货币成本。

## 用法

从项目根目录运行：

```bash
python -m storage.arena_analysis /path/to/replays
```

默认在 `/path/to/replays/analysis/` 写出：

- `arena_report.json`：完整的分组、样本质量分布、指标分子/分母与局限说明。
- `arena_report.csv`：每个板子与好人/狼人模型组合一行，便于用电子表格继续分析。

也可以指定输出目录：

```bash
python -m storage.arena_analysis /path/to/replays --output-dir /path/to/report
```

## 样本政策

- 主要结果只纳入已结束、胜者明确、板子和双方模型已知、API 质量为 `valid` 的对局。
- `degraded`、`invalid`、`unknown` 质量和中断对局保留在样本质量计数中，但不进入主要胜率和策略指标分母。
- 统计指标按各局分子与分母分别求和后计算，不对百分比做简单平均；分母为零的指标保持缺失，不按 0 计分。
- 重复 `game_id` 只计一次；损坏或超出 2 MiB 的 manifest 会被跳过并记录原因。
- 结果按板子、规范化 API 服务端点、好人/狼人模型、温度、超时、反应预算及源码/提示词指纹分组。缺失这些实验条件的旧档会保留在质量统计中，但不进入主要胜率分母。
- 不同组合没有自动随机化或交叉平衡，不能将报告解读为全局模型排行榜。

## 运行边界

工具仅读取每局目录中的 `manifest.json`，不会加载提示词、完整私密记忆或原始 API 日志；不会修改原始归档。它不会调用模型，因而不产生模型费用。后续若要启动真实批量对局，必须另行确认实验设计、预算上限和停止条件。
