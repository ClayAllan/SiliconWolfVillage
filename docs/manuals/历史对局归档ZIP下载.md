# 下载历史对局归档 ZIP

## 如何操作

1. 使用创建对局的浏览器会话打开硅基狼村，等待一局正常结束或在同一会话中使用已生成的历史归档。
2. 在左侧 **「📜 复盘与导出」** 展开 **「📦 历史对局归档 ZIP（仅供私人保存）」**。
3. 选择目标历史对局，阅读隐私提醒并勾选确认。
4. 点击一次 **「⬇️ 生成并下载历史对局归档 ZIP」**。应用会在下载请求到来时按需打包并返回 ZIP；如果打包失败，下载控件会显示错误原因。
5. 若要交给其他人分析，优先使用受信任的渠道，确认理解包含的私密资料，不要上传到公开仓库、公开讨论区或未经授权的服务。

> 私密 ZIP 与此前的 **「📤 下载所选私密进度存档」** 不同：进度存档用于以后继续游戏；历史归档用于规则审查、模型分析与复盘取证。

## 文件内容与限制

只会打包**当前浏览器会话所拥有的一个归档文件夹**中的标准文件：

- `manifest.json`：规则版本、模型配置、对局结果和可核验指标。
- `summary.md`：赛后复盘摘要。
- `final_state.json`：终局状态、真实身份、模型私密状态与统计。
- `events.jsonl`：原始事件。
- `api_calls.jsonl`：模型请求与结果诊断。
- `memory.jsonl`：AI 记忆相关的私密记录。
- `runtime.log`：对局运行日志。
- `replay_frames.jsonl`、`replay_items.jsonl`、`replay_manifest.json`：存在时加入授权展示帧归档。
- `session.json`：仅在原归档包含该标准文件时加入。
- `PRIVATE_ARCHIVE_NOTICE.txt`：ZIP 内的隐私提示。

不递归打包额外文件，不包含其他对局、跨局 `index.csv` 或系统临时目录。文件缺失时保留已有的标准归档内容，但必须存在有效的 `manifest.json`。

为避免服务因大文件压缩而卡顿，单个文件最大 32 MiB，整个归档的未压缩文件总量和 ZIP 最大 64 MiB；超限时显示错误，不会静默丢弃大文件以假装导出完整。使用 Streamlit 延迟下载接口：只有用户点击下载时才生成可下载流，不会把 ZIP 字节长期保存在会话状态中，也不会在正常页面轮询时反复压缩。下载文件名使用兼容性更好的 ASCII 名称。

## 隐私与权限

- 此功能仅在房主工作台提供，**普通受邀观众无下载入口**。
- 真人席位处于尚未结束的受限视角时，不可获取包含所有身份与私密推理的完整 ZIP；对局结束后可导出。
- ZIP 不是公开观战包，也不是匿名化数据。原始日志或历史用户输入可能含敏感文本；分享前需自行核查。
- 应用正常归档流程不主动记录 API Key，打包程序也不会添加 API Key；但对历史文件中的任意自由文本不作绝对无密钥保证。
- 使用的是该浏览器会话的隔离档案目录。服务重启、会话丢失或临时文件被清理后，旧档不保证还能下载；建议对局结束后及时保存 ZIP。

## 验证方式

`tests/test_archive_zip.py` 覆盖标准文件保留、跨会话路径拒绝、目录/文件符号链接拒绝、损坏 manifest、大小上限及最近档案筛选。

`tests/test_app_integration.py` 覆盖私密确认、延迟下载控件和受限视角拦截；`tests/test_archive_zip.py` 同时验证延迟下载返回可读取的 ZIP 文件流。CI 使用虚构离线归档，不发起模型 API 请求，也不依赖付费对局。
